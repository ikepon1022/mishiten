# みしてん v1.0.0

静岡県三島市の今日・明日の天気を表示する、スマートフォンとPC対応のPWAです。

## 公開する

このフォルダーのファイルを、HTTPS対応の静的サイトホスティング（GitHub Pages / Netlify / Cloudflare Pages など）に配置してください。`index.html` がサイトのトップに来るようにします。HTTPSで公開するとホーム画面にインストールできます。ローカル開発時は `localhost` でも動作します。

**注意:** URLを知っている人が閲覧できる構成です。完全な非公開には、ホスティング側のアクセス制限が必要です。

## インストール

- iPhone: Safariで公開URLを開き、共有 → ホーム画面に追加。
- Android: Chromeで公開URLを開き、メニュー → アプリをインストール（またはホーム画面に追加）。
- PC: Chrome/Edgeで公開URLを開き、アドレスバーのインストールアイコンから追加。

## アップデート

1. `app.js`, `style.css`, `index.html` などを編集します。
2. `sw.js` の `CACHE` のバージョン番号を変更し、必要に応じて `app.js` の `VERSION` と画面内の `v1.0.0` を変更します。
3. 公開先にファイルを再アップロードします。
4. インストール済みアプリは次回起動または再読み込みで更新版を取得します。反映には再起動が必要な場合があります。

天気データ: Open-Meteo API（インターネット接続が必要）。通信できないときは最後に保存した予報を表示します。データが古い場合があります。
