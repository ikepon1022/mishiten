# みしてん v1.2.0（通常PWA版）

三島市の今日・明日の天気を表示するPWA。天気・気温に応じて三島市、沼津市、裾野市、長泉町、清水町のスポットを提案します。

- 天気データのみOpen-Meteo APIを使用します。
- おすすめスポットはアプリ内の固定データで、外部スポットAPIは使いません。営業状況は確認してください。
- ダークモード、背景、服装アドバイス、時間別予報、予報キャッシュは維持。
- GitHub Pagesへはこのフォルダ内のファイルをリポジトリのルートに配置してください。
- 更新後はPWAのキャッシュ更新のため再読み込みや再起動が必要な場合があります。
